EventDiffusion

Learning Native Event Stream Distribution from Videos

EventDiffusion samples individual events, each with its pixel, polarity and continuous timestamp, from a distribution learned on real event-camera recordings. It generates the events between RGB frames, and predicts future events.

Karthik Sundar Senthilkumar, Christopher Thirgood, Simon Hadfield

Paper soon Code soon See how it works
How it works

How many, where, and when.

EAD - Event Activity Diffusion samples how many events fire in each cell and slice, ESA - Event Spatial Allocation places them on pixels, and ETD - Event Timing Diffusion gives each one a continuous timestamp.

Metric

CEFS: scoring event-stream fidelity.

The Composite Event Fidelity Score compares a generated stream with the paired recording over the same interval and sensor area. It needs no trained network, no count matching and no realignment. It provides an analytical way to say how close an event stream is compared to a real event stream.

Why a new score? PECS can overlook excess events near real ones, and EQS is insensitive to some count errors: an empty output receives an EQS of 0.94 or higher despite missing all real activity. CEFS lies in [0, 1], equals 1 for an identical stream, and splits into count fidelity and shape fidelity. It will be released as a standalone package.
